# Pocket Oracle

A pocket tarot grimoire with an **open-weight AI reader**. The complete 78-card Rider-Waite deck — meanings, correspondences, imagery notes — plus a draw ritual and a symbolic reading generated by an open-weight language model.

Built for **Hacktoberfest 2026 · DEV Challenge — Week 2** (theme: *Side Hustle* — build something with open-weight models or open-source AI that someone would actually pay for).

## Origin and credit

This project grows out of **[Tarot Rider-Waite](https://github.com/jrpasolini/Tarot-Rider-Waite)** — an interactive Portuguese-language grimoire of the 78 cards, built by **Antonio Pasolini** and **Renata Sheila**, which already ships the card dataset, the draw flow and a Cloudflare Workers AI interpretation endpoint.

**Pocket Oracle is a new build.** It starts on **2026-10-15**, inside the Hacktoberfest 2026 challenge window, and takes that grimoire as its foundation. Everything added in this repository is developed during the challenge window; what came from the original project is credited above and kept clearly separated.

The original Portuguese text of the app is preserved in [`README.pt-BR.md`](README.pt-BR.md).

Rider-Waite card images are public domain, obtained from a collection based on the Wikimedia Commons archive.

## Stack

- **Static PWA** — no build step, no framework, no bundler
- **Cloudflare Worker** (`cloudflare-worker.js`) as the AI backend
- **Cloudflare Workers AI** for the readings — an **open-weight** model
- Deployed on **GitHub Pages**

## How it works

1. The user writes a question and draws one card, or three (Past / Present / Future).
2. The front end sends only the question and the drawn cards to the Worker.
3. The Worker validates the payload, builds the prompt and calls an open-weight model through Workers AI.
4. The model returns a **structured JSON reading** (strict schema), which the front end renders as sections.

The deck itself, the search, the filters and the draws all work **offline** — only the optional AI reading needs the network.
